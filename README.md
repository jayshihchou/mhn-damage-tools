# MHN 傷害計算器

Monster Hunter Now 的傷害計算與配裝工具，純前端靜態網頁，資料都在瀏覽器裡計算。

## 頁面

- **傷害計算器**（`index.html`）：輸入武器、技能與招式，看打在每個部位的傷害。
- **最高傷害配裝**（`build.html`）：選怪物部位、招式和戰鬥狀況，自動找出傷害最高的武器、防具與漂流石組合。
- **配裝編輯**（`loadout.html`）：自己換武器、防具、漂流石，傷害即時重算；可用技能篩選裝備。
- **配裝比較**（`compare.html`）：最多 5 套配裝並排比較。

## 說明

- 目前武器資料只有大劍 10-5。
- 配裝搜尋結果為近似最佳解。
- 選項與比較列只存在你自己的瀏覽器（localStorage）。

本工具為玩家自製，與 Niantic、CAPCOM 無關。遊戲名稱、怪物與裝備名稱版權屬原權利人。
